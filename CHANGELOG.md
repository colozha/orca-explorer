# Changelog

## 0.1.0 — development, 2026-10-07

Based on upstream Dolphin 26.08.2.

- Introduced the independent Orca Explorer name, launcher ID and executable.
- Made GNOME Files appearance the default for fresh configurations, retaining Dolphin Classic.
- Separated settings, state, bookmarks, Places, folder properties, D-Bus routing, libraries and bundled integration helpers from Dolphin.
- Disabled fork telemetry to KDE and directed support links to the fork repository.
- Added original CC0 orca/folder artwork and fork documentation.

This entry records preparation of the development version, not a published release.
